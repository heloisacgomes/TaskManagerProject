To Do – O que faremos hoje?

Sistema de gerenciamento de tarefas desenvolvido em Java com JavaFX e MySQL.

O projeto permite cadastrar, editar, concluir e remover tarefas por meio de uma interface gráfica intuitiva, proporcionando uma forma simples e organizada de acompanhar atividades do dia a dia.

Funcionalidades:

Cadastro de tarefas
Edição de tarefas
Exclusão de tarefas com confirmação
Marcação de tarefas como concluídas
Exibição visual de tarefas concluídas
Persistência de dados em banco de dados

Tecnologias Utilizadas:

Java 25
JavaFX
FXML
CSS
JDBC
MySQL
Maven
JUnit

Conceitos Aplicados:

Programação Orientada a Objetos (POO)
Generics
Padrão DAO (Data Access Object)
Persistência de dados com JDBC
Interface gráfica com JavaFX
Separação entre interface e lógica utilizando FXML
Estilização com CSS
Testes automatizados com JUnit

Estrutura do Projeto:

Tela principal para visualização das tarefas
Tela de cadastro e edição
Camada de persistência utilizando DAO
Integração com banco de dados MySQL
Testes unitários para validação das funcionalidades

Objetivo:

Este projeto foi desenvolvido com o objetivo de aplicar conceitos fundamentais de desenvolvimento de software, incluindo orientação a objetos, interfaces gráficas, persistência de dados, testes automatizados e boas práticas de organização de código.
